# Explorations

A fresh start under the project's original premise: use formal mathematics and exact
computation to check claims about physics and about the software that makes such
claims. Work here keeps the project's core discipline (preregistration before results,
planted mutants that must be caught, every outcome reported) but none of the legacy
sealing and attestation machinery. It does not depend on the gravity-measurement work
in `Experiments/`.
