# G-dimensional coincidences

`candidates.csv` is a reproducible numerical-observation artifact generated by:

```bash
python -m Discovery.dimensional_search
```

Every row has dimensions exactly equal to `M^-1 L^3 T^-2`; this is a filter, not a
discovery claim. The score primarily ranks closeness to the measured magnitude of `G`,
with small penalties for exponent and expression complexity. It is not a probability,
confidence level, or measure of physical plausibility.

Candidates involving a Planck unit are not independent predictions of `G`, because the
standard Planck-unit definitions themselves contain `G`. They are retained as useful
positive controls for the search implementation.
