# Gravity Universality — Pilot 0

**PROPOSED PROTOCOL — INDEPENDENT REVIEW PENDING.**

This is a separately scoped literature-method pilot within The Number Project. The question is whether selected published constructions support a defensible disagreement about the same observable under shared physical conditions. It is not a claim that gravity is emergent or that three complete microscopic theories have already been shown equivalent.

## Current package

Phase A contains a registered proposed protocol, seven version-pinned source identities, empty mapping/comparison templates, a publication receipt and an independent-review prompt. Full-text comparative extraction and scientific findings have **not started**. Source preparation checked abstracts and version metadata, not the complete derivations. Prior exploratory exposure is explicitly disclosed.

[Protocol revision 1](protocol.md) is the controlling scientific and scoped work specification. [Registration receipt](registration.json) identifies its sole-file commit and the actual draft-PR timestamp. [Source register](sources.md) distinguishes primary calculations, reference checkpoints and background. [Theory maps](theory_maps.md) and [comparison tables](comparison.md) remain deliberately unpopulated. [Independent protocol-review prompt](review.md) is ready to use; no independent reviewer has yet accepted this package.

## What happens next

The next gate is independent protocol review. Only after acceptance is recorded against the applicable immutable revision may the bounded full-text extraction and screening proceed. All three constructions receive maps, all ten dimensions are recorded, and at most one candidate is examined in detail. A complete study that cannot establish a common comparison is still informative; missing predictions must not be invented to produce a positive result.

The initial corpus is intentionally small and historically focused. It is not a survey of the latest research. Adding sources or substituting models requires an explicit prospective revision rather than silently expanding until an attractive fork appears.
